# Interactive Study & Quiz Platform

A desktop learning application built in C# using Object-Oriented Design (OOD) principles. Features dynamic quiz generation, course management, automated scoring logic, student progress tracking, and interactive leaderboards.

## Features
- **Dynamic Quiz & Course Management:** Encapsulates questions, options, and quiz criteria into modular data structures.
- **Automated Scoring Engine:** Evaluates user submissions in real-time and logs scoring metrics.
- **Progress Tracking & Leaderboard:** Tracks quizzes taken, aggregate scores, and average score stats for student mastery comparisons.

## Tech Stack
- **Language:** C# (.NET 8.0 / .NET Core)
- **Design Pattern:** Object-Oriented Design (Encapsulation, Domain Modeling)

## Quickstart & Build Instructions

### Prerequisites
Make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.

cd Interactive-Study-Platform
